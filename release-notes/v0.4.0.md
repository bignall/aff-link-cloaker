# v0.4.0: Public API for other plugins

Other plugins (such as Ad Network) can now use your cloaked links and their click counts through
a small, stable set of functions instead of the plugin's internal classes.

## Update

Upload **aff-link-cloaker-0.4.0.zip** under **Plugins → Add New → Upload Plugin** and choose
**Replace current with uploaded**. The extension hasn't changed.

## New

- `alc_cloaked_url( $id_or_slug, $subid )`, `alc_get_link_id()`, `alc_get_links()`,
  `alc_link_is_dead()` and `alc_link_post_type()`.
- `alc_click_counts()`: clicks by link, sub-ID and day, e.g. how many clicks each ad sent.
- Check `function_exists( 'alc_api_version' )` before calling them.
- The clicks table gets an index on the sub-ID, added automatically on update.
