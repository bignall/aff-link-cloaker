Maintenance release on top of [v0.2.0](https://github.com/bignall/aff-link-cloaker/releases/tag/v0.2.0).

## Install

Download **aff-link-cloaker-0.2.1.zip** below, then in WordPress go to **Plugins → Add New → Upload Plugin**. If 0.2.0 is installed, WordPress offers to replace it; your links, clicks and settings are kept. Requires **PHP 8.1+** and **WordPress 6.4+**.

## Changes

- After importing offers or pasting links, each created link in the confirmation message links to its edit screen again.
- Updated [wp-foundation](https://github.com/bignall/wp-foundation) to 0.1.3. Deleting the plugin (with "Delete all links…" ticked) now also removes WordPress's cached hierarchy for link categories, so no data is left behind.
- Release builds now resolve dependencies for PHP 8.1, the plugin's minimum.
