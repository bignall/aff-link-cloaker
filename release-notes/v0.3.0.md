# v0.3.0: JVZoo support and browser extension

Adds JVZoo as a second affiliate network, with a browser extension that imports the products you're approved to promote.

## Install

Download **aff-link-cloaker-0.3.0.zip** below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded** if an older version is installed. Your links, clicks and settings are kept. Requires **PHP 8.1+** and **WordPress 6.4+**.

## What's new

- **JVZoo links:** paste them under **Affiliate Links → Import Offers → Paste links**. Both `https://www.jvzoo.com/c/<affiliate ID>/<product ID>` and JVZoo's short `jvz1.com`–`jvz9.com` links work.
- **Product names filled in:** leave the name out and it's read from JVZoo's public Affiliate Information page for the product.
- **Sub-IDs reach JVZoo:** `/go/your-link/facebook/` sends the visitor to your JVZoo link with `?tid=facebook`, so the source shows in your JVZoo affiliate stats.
- **No duplicates:** the same JVZoo product pasted again (even from a different short domain) is skipped.
- **Safer pasting:** pasting a network's page instead of your affiliate link, such as a WarriorPlus offer page or a JVZoo product page, is rejected with an explanation, instead of creating a link that earns nothing.

- **Browser extension (new):** while you're signed in to JVZoo, open **Affiliates → Approved Products**, click the extension and **Scan this page**, then **Create cloaked links**. Download **aff-link-cloaker-extension-0.1.0.zip** below and follow the [extension's README](https://github.com/bignall/aff-link-cloaker/blob/main/browser-extension/README.md) to install it and connect it with a WordPress Application Password.
- **Shortcodes are easier to copy:** the edit screen shows the shortcode with a Copy button, and the links list has a Shortcode column.
- **Short description:** WordPress's Excerpt box on the edit screen is now a "Short description" box for notes about the product.

## Why JVZoo needs the extension

Unlike WarriorPlus, JVZoo's API only covers vendors' own products and their affiliates. It can't list the products you're approved to promote or give your affiliate links, so the extension reads them from JVZoo's pages in your own browser while you're signed in. You can also paste JVZoo links by hand.

The extension was built without access to a signed-in JVZoo account, so it was tested against pages that imitate JVZoo's. If a scan finds nothing on your Approved Products page, please report it with a saved copy of the page.
