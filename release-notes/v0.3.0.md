# v0.3.0: JVZoo support

Adds JVZoo as a second affiliate network.

## Install

Download **aff-link-cloaker-0.3.0.zip** below, then in WordPress go to **Plugins → Add New → Upload Plugin** and choose **Replace current with uploaded** if an older version is installed. Your links, clicks and settings are kept. Requires **PHP 8.1+** and **WordPress 6.4+**.

## What's new

- **JVZoo links:** paste them under **Affiliate Links → Import Offers → Paste links**. Both `https://www.jvzoo.com/c/<affiliate ID>/<product ID>` and JVZoo's short `jvz1.com`–`jvz9.com` links work.
- **Product names filled in:** leave the name out and it's read from JVZoo's public Affiliate Information page for the product.
- **Sub-IDs reach JVZoo:** `/go/your-link/facebook/` sends the visitor to your JVZoo link with `?tid=facebook`, so the source shows in your JVZoo affiliate stats.
- **No duplicates:** the same JVZoo product pasted again (even from a different short domain) is skipped.
- **Safer pasting:** pasting a network's page instead of your affiliate link, such as a WarriorPlus offer page or a JVZoo product page, is rejected with an explanation, instead of creating a link that earns nothing.

## Why there's no JVZoo offers list

Unlike WarriorPlus, JVZoo's API only covers vendors' own products and their affiliates. It can't list the products you're approved to promote or give your affiliate links, so JVZoo links are added by pasting them.
