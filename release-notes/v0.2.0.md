# v0.2.0: WarriorPlus API import

Pull your approved WarriorPlus offers into WordPress and turn them into short, cloaked, trackable links, e.g. `https://yoursite.com/go/ai-video-maker/`.

## Install

Download **aff-link-cloaker-0.2.0.zip** below, then in WordPress go to **Plugins → Add New → Upload Plugin**. Requires **PHP 8.1+** and **WordPress 6.4+**.

Then:
1. **Affiliate Links → Settings:** paste your WarriorPlus API key (WarriorPlus → My Account → API Key) and click **Test WarriorPlus connection**.
2. **Affiliate Links → Import Offers:** tick your approved offers and create cloaked links.

## What's new in 0.2.0

- **WarriorPlus API import:** lists every offer you're an affiliate for (V2 API), with an *Approved only* filter. Links use the same affiliate URL as WarriorPlus's "Get Link" button.
- **Paste a list of links** from any network (`Name | URL`, one per line).
- **Twice-daily sync:** keeps affiliate URLs and offer names current, flags offers you've been paused or banned from or that have ended, and can create links for newly approved offers.
- **Fallback URL** for clicks on dead offers.
- **Click tracking** with sub-IDs (`/go/slug/facebook/`). Bots and link checkers are ignored, and IPs are stored only as salted hashes.
- Rebuilt on [wp-foundation](https://github.com/bignall/wp-foundation): clean activation, upgrades, multisite, and opt-in data removal on uninstall.

## Upgrading from 0.1.0

Existing links are migrated automatically and keep sending clicks to the same destination. The "affiliate ID" setting and page scraping were removed.

## Known limits

- Not yet tested against a live WarriorPlus account. The import was built from WarriorPlus's API docs and example data.
- Sub-IDs are recorded in your click log but not passed on to WarriorPlus.
- The WarriorPlus V2 API is marked beta by WarriorPlus.
