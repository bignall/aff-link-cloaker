Affiliate Link Cloaker

Connect the extension to your WordPress site so it can create cloaked links for the JVZoo products you're approved to promote.

Create one in WordPress under Users → Profile → Application Passwords (name it "Link Cloaker extension"). It only works over HTTPS. Leave blank to keep the saved one. It's stored in this browser only.

The first number in your JVZoo links: https://www.jvzoo.com/c/12345/67890. Only needed if a page shows products but none of your links.
